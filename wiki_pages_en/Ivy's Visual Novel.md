# Ivy's visual novel

“This is going to be exciting!”

This page contains game content that is unfinished, work in progress, or unavailable in standard gameplay.

**Ivy's visual novel** is an upcoming *Deadlock* visual novel.

The novel is accessible in-game through the console command citadel_book_open 3, but only the audio is available and it is currently incomplete. The audio available so far has been archived on YouTube.

See also Ivy's visual novel/Transcription.
