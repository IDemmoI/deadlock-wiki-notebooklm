# Ranked mode

“Farewell, my friends.”

This page contains game content that has been removed from the game.

In-game description of Ranked mode

*For the current rank system, see Skill Rating.*

“

Ranked is a challenge mode that provides a more competitive Deadlock experience where you'll be matchmade with players of similar skill to determine your Skill Rank among the global population.

**Ranked mode** was a game mode in Deadlock for competitive players to compete with other players of similar skill levels. By winning matches and performing well, players could earn badges for their profile depending on the highest rank they achieve.

Medals were updated once per week, requiring at least 7 games played within that week to receive a rank. [1]

Ranked mode was added to the game on October 10, 2024, but was not publicly available until October 15th. Medals were granted the following Tuesday, on October 22nd. The gamemode was removed on November 21st. Ranks still appears in a player's profile as Skill Ratings.

## Overview

[edit | edit source]

The rank badge can be found by viewing the profile. In ranked mode, an additional small icon was displayed when hovering other player's profiles and on the hero's icon in the end game stats.

In order to play, players:

- Had to have 50 games played
- Had to have zero behavior-related restrictions (Voice/text bans, report misuse, etc.)

## Ranks

## Update history

| November 21, 2024 | [ Matchmaking Rework ]    - This update includes a new version of the matchmaker. The matchmaking pools are no longer split between normal and ranked, there is only one primary matchmaking mode and there are no limited hours. |
| October 18, 2024 | - We have adjusted the matchmaking schedule to not be split across many different hours throughout the day, primarily to help address queue times. There will now be a wider continuous, but more concentrated, set of hours that it is enabled in.
